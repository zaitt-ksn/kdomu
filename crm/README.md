# К дому Outreach CRM

Локальная CRM касаний приютов — **тот же UX, что Tango Outreach**:
Сегодня → Копировать+отправлено → журнал → следующий шаг cadence.

## Как открыть

**Вариант 1:** дважды кликните `open.command`

**Вариант 2:**

```bash
cd crm
python3 -m http.server 8766 --bind 127.0.0.1
```

Откройте: http://127.0.0.1:8766

## Как работать (не путаться)

1. Вкладка **Сегодня** — очередь на день (Москва, приоритет A)
2. Читаете текст → **Копировать+отправлено**
3. CRM сама:
   - копирует письмо
   - пишет в **Журнал**
   - меняет статус контакта
   - создаёт следующий шаг (FU → пинг → визит → пауза → +90)
4. Если ответили — кнопки **Ответили / Визит / Карточки**

## Вкладки

| Вкладка | Зачем |
|---|---|
| Сегодня | очередь касаний |
| Все задачи | весь cadence |
| Журнал | что уже отправили |
| Контакты | приюты и статусы |
| Письма | шаблоны |
| Правила | KPI и напоминалки |
| Настройки | экспорт/импорт/сброс |

## Данные

Хранятся в `localStorage` браузера.  
Раз в неделю: **Настройки → Экспорт JSON**.
